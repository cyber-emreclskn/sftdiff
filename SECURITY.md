# Security policy

Security fixes target the latest release and the current `main` branch. This
project is in alpha; older versions do not have a separate maintenance branch.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting form](https://github.com/cyber-emreclskn/sftdiff/security/advisories/new).
Please do not disclose vulnerabilities in public issues or pull requests before
a fix has been coordinated.

Include the affected version, reproduction steps, expected impact, and a small
synthetic snapshot if relevant. Never include credentials, proprietary training
data, or personal information. No response-time guarantee is offered.

## Handling snapshots and reports

Snapshots and generated reports may contain training examples and decoded text.
Review their contents before sharing them. Reports render snapshot content as
text and use local assets, but should still be treated as potentially sensitive
data. Use synthetic examples for issues, tests, and demonstrations.
